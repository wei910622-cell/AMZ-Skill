AMZ-Skill｜Amazon Listing & Keyword Analysis AI Skills
AMZ-Skill 是一套面向跨境电商运营的 Amazon AI Skill 工作流，覆盖关键词分析、竞品研究、评论洞察、产品资料整理、Listing 优化与合规检查。它不是单次提示词，而是一套可复用的智能体工作手册，适合在 Codex、Claude Code、Cursor、Trae、QoderWork、CodeBuddy 等工具中使用。

AMZ-Skill is a reusable AI skill workflow for Amazon cross-border ecommerce operations. It supports keyword analysis, competitor research, review insight mining, product fact organization, listing optimization, and compliance checks. Instead of one-off prompts, it provides structured agent playbooks that can be used across Codex, Claude Code, Cursor, Trae, QoderWork, CodeBuddy, and similar AI coding tools.

核心能力｜Core Capabilities
Amazon 关键词分层、相关性预审与关键词溯源

竞品 ASIN、标题、五点、评论和搜索结果分析

Listing 标题、目标受众、风格、五点、长描述、ST、主副图建议词和 A+ 模块优化

支持单 ASIN、批量 ASIN、父子体 ASIN 的关键词分配

根据产品事实过滤不相关、高风险或未确认关键词

输出 Excel / HTML 格式，便于运营审核、团队协作和发布前检查

Amazon keyword tiering, relevance pre-review, and keyword provenance

Competitor ASIN, title, bullet, review, and search-result analysis

Listing optimization for title, target audience, style, bullets, long description, ST, image copy, and A+ modules

Support for single ASINs, batch ASINs, and parent-child variation keyword allocation

Product-fact-based filtering for irrelevant, risky, or unsupported keywords

Excel / HTML outputs for operator review, team collaboration, and pre-publishing checks

适用场景｜Use Cases
新品上架前的关键词与 Listing 规划
老品标题、五点、长描述和 ST 优化
竞品关键词反查后的埋词策略确认
父子体变体之间的关键词分配
根据 Amazon 新规检查标题字符数、敏感词和高风险声明
将卖家精灵、Sorftime、Apify、ABA/SQP、广告词报表等数据转成可执行的 Listing 优化方案
推荐工作流｜Recommended Workflow
使用关键词分析 skill 完成关键词挖掘、分层和初步策略。
使用竞品/评论分析 skill 提取买家痛点、场景和市场表达。
使用 amazon-listing-optimizer 对关键词做相关性预审。
用户确认关键词、产品事实和待确认问题。
生成最终 Listing 优化结果，包括标题、目标受众、风格、五点、长描述、ST、主副图建议词和 A+ 模块建议词。
输出 Excel 或 HTML，供运营审核和上架使用。
设计原则｜Design Principles
先确认产品事实，再生成文案
关键词必须严格溯源
高流量词不能覆盖产品事实
不写未证实的认证、材质、功效或夸大声明
待确认问题先和用户沟通，不隐藏在最终 Excel 里
Listing 优化与关键词分析分工明确，避免一个 skill 变成大而全的玩具
