# AMZ-Skill｜Amazon Listing & Keyword Analysis AI Skills

AMZ-Skill 是一套面向跨境电商运营的 Amazon AI Skill 工作流，用于关键词分析、竞品研究、评论洞察、产品资料整理、Listing 优化与合规检查。

AMZ-Skill is a reusable AI skill workflow for Amazon cross-border ecommerce operations, covering keyword analysis, competitor research, review insights, product fact organization, listing optimization, and compliance checks.

## Core Capabilities｜核心能力

- Keyword relevance pre-review and keyword provenance
- Competitor ASIN, title, bullet, review, and search-result analysis
- Listing optimization for title, target audience, style, bullets, long description, ST, image copy, and A+ modules
- Support for single ASINs, batch ASINs, and parent-child variation keyword allocation
- Product-fact-based filtering for irrelevant, risky, or unsupported keywords
- Excel / HTML outputs for review and publishing
